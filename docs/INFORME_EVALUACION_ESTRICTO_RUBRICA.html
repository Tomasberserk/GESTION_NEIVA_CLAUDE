3. Recordatorio de Credenciales Sensibles y Llaves Secretas por Configurar

Por cumplimiento de seguridad (Criterio 1.5, Artículo VIII de la Constitución y regla GOV-06), ninguna llave secreta real se guarda en Git. Para levantar en local (archivo .env) o en producción (Render / Vercel), asegúrate de configurar estas variables exactas:

Tabla 3
Inventario maestro de credenciales sensibles y variables de entorno requeridas por el sistema
Variable de Entorno Dónde se Configura ¿Obligatoria? Descripción y Cómo Obtenerla / Generarla
DATABASE_URL .env (Local) / Render SÍ (Crítica) En local con Docker: postgresql://gestion_user:gestion_pass@localhost:5432/gestion_neiva.
En producción: Cadena de conexión Transaction/Session Pooler de Supabase PostgreSQL.
SECRET_KEY .env (Local) / Render SÍ (Crítica) Clave criptográfica para firmar los tokens JWT HS256. Genérala con:
python -c "import secrets; print(secrets.token_hex(32))"
SUPERADMIN_KEY .env (Local) / Render SÍ (Crítica) Llave privada para el header x-superadmin-key que protege el panel /superadmin y la gestión de planes/trials.
REDIS_URL .env (Local) / Render Recomendada En local con Docker: redis://localhost:6379/0. En producción: URL de Redis Cloud / Upstash / Render Redis para sesiones del Agente IA.
GEMINI_API_KEY / GOOGLE_API_KEY .env (Local) / Render Para Modo Voz / IA Llave de API de Google AI Studio (Gemini 2.5 Flash) para procesamiento de intenciones en lenguaje natural cuando el parser determinista delega al LLM.
