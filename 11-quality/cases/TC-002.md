1. Clean SQLite in-memory or PostgreSQL test database initialized with all Alembic migrations (`001` through `013`).
2. Active tenant company (`Empresa`) provisioned with valid JWT credentials and isolated `empresa_id`.
3. Module boundary rules (`import-linter`) passing with zero cross-module internal imports.

| Step | Action | Expected Result |
|---|---|---|
| 1 | Authenticate tenant user and obtain Bearer JWT | Returns HTTP `200`/`201` with signed HS256 token and `X-Correlation-ID` header |

| 3 | Verify database state and cross-tenant isolation | Records persisted under `empresa_id`; cross-tenant access returns `403`/`404` |
