# SCR-04 — Dashboard Financiero y Cierre de Caja

## Identification

| Field | Value |
|---|---|
| Screen | Panel Principal y Resumen (`/dashboard`) |
| Serves | `HU-11`, `HU-12` |
| Route | `frontend/src/pages/Dashboard.jsx` |

## States

| State | What the user sees |
|---|---|
| Empty Day | Zero sales registered today; cards display `$0.00` and prompt: "Registra tu primera venta" |
| Loading | Pulse animation over KPI cards and chart area |
| Populated | 4 metric cards (Ventas Hoy, Transacciones, Stock Crítico, Por Vencer), sales chart, and export button |
| Exporting | Excel button disabled: "Generando hoja de cálculo..." |

## User actions

- **Descargar Excel:** Streams `.xlsx` spreadsheet generated by `reportes_analytics` via `openpyxl`.
- **Ver Productos por Vencer:** Navigates directly to `/inventario` filtered by critical expiration.
- **Ver Stock Crítico:** Navigates directly to `/inventario` filtered by low stock.
